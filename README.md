# Cerrajero Barcelona

Sitio estático para GitHub Pages: https://cerrajeroeurokey.github.io/cerrajero-barcelona/

156 páginas HTML; 73 barrios, 30 municipios, 16 servicios y 28 artículos.

Sube el contenido de este ZIP a la raíz de la rama main del repositorio cerrajeroeurokey/cerrajero-barcelona. Settings > Pages > Deploy from a branch > main > /(root).

IMPORTANTE: fechas de blog editoriales, no historial real de publicaciones. Sustituye datos legales, confirma disponibilidad, cobertura y servicios, añade opiniones reales con autorización. Los SVG son ilustraciones originales vectoriales, no fotografías de trabajos reales.
